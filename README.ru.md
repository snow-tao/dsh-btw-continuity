# DSH BTW Continuity

Непрерывные побочные вопросы в DeepSeek Harness: одна хронологическая панель на сессию, уточняющие вопросы и никакого прерывания основной задачи.

## Возможности

- Все вопросы и ответы BTW сессии отображаются в одной хронологической панели.
- Нижнее поле позволяет задавать уточняющие вопросы: Enter отправляет, Shift+Enter добавляет новую строку.
- Поле начинается с одной строки, увеличивается до четырёх, затем прокручивается внутри и возвращается к одной строке после отправки.
- X только скрывает панель; следующий вопрос восстанавливает видимую историю.
- Значок корзины очищает историю BTW текущей сессии и позволяет начать заново.
- Ответы не попадают в основной диалог по умолчанию; `send_message` используется только по явному запросу.
- Ответы только для чтения, вопросы по выделенному тексту, Markdown, формулы, копирование и восемь языков.

## Требования

- DeepSeek Harness `>=0.2.0-rc.1 <0.3.0-0`
- Node.js 22+
- Настроенный поставщик модели

**Этот пакет является модификацией `@michengai/dsh-btw`. Оба регистрируют `/btw`, поэтому их нельзя включать одновременно.**

## Установка

Замените `desktop` на имя вашего профиля:

```bash
dsh plugin --profile desktop add dsh-btw-continuity@latest --registry=https://registry.npmjs.org/
```

Если активация не произошла автоматически, перезагрузите настольное приложение или перезапустите соответствующую службу DSH.

## Использование

```text
/btw Кратко опишите текущее предложение одним предложением
```

Вы также можете выбрать `btw` в меню `/` или использовать **Спросить BTW** на выделенном тексте.

Разверните панель и используйте нижнее поле. Вопросы из панели и `/btw` используют одну и ту же историю.

| Действие | Поведение |
| --- | --- |
| X | Скрывает панель без удаления истории; следующий вопрос восстанавливает её. |
| Корзина | Очищает всю историю BTW этой сессии и удаляет панель. |
| Копировать | Копирует исходный Markdown соответствующего ответа. |

## История и конфиденциальность

- Последующие запросы включают завершённые раунды BTW и контекст основной сессии, что может увеличить расход токенов.
- Запросы отправляются только настроенному поставщику модели; новый сторонний получатель не добавляется.
- История хранится в памяти Host и теряется при его перезапуске. Скопируйте ответы, которые нужно сохранить.

## Настройки

В **Плагины → BTW Continuity → Настроить** можно разрешить инструменты кроме `send_message` (по одному на строку) и заменить встроенный промпт. По умолчанию доступны только текстовые ответы.

## Удаление

```bash
dsh plugin --profile desktop remove dsh-btw-continuity
```
